# 🧪 动手实验 · 里程碑 4

> **本里程碑的交付物**：① 解析选型说明 ② 版面层级保留方案 ③ 噪声清洗规则表 ④ 解析失败降级与告警路径 ⑤ 抽样验收表 ⑥ 人工兜底清单。
> **验收标准**：抽任意一份语料，你能说出它走哪条链路、拿到什么结构、失败时触发什么动作；抽样表上有 30 份文档的数字。
>
> 三档任选：**档位 A 真实项目**（在你自己的语料上跑）／**档位 B 本地练习**（拿公开 PDF 与自制扫描件做对照）／**档位 C 纸上评审**（30 分钟，判断力训练）。

## 档位 A · 真实项目（推荐）

### 1. 先给语料分层，再抽样

```bash
# 按扩展名看类型分布，决定要维护几条链路
find /path/to/corpus -type f | sed 's/.*\.//' | sort | uniq -c | sort -rn | head
# 分层：随机取 30 份，覆盖 PDF/Office/HTML 与大小各档
```

### 2. 逐份跑解析，填质量表

对每份文档记录：

| 文档 | 类型 | 解析链路 | 字符/页 | 乱码率 | 标题召回 | 表格可读 | 噪声残留 | parse_status |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

```bash
# 快速分诊：无文本层 → 直接走 OCR
pdffonts sample.pdf | head
pdftotext -layout sample.pdf - | wc -c
```

### 3. 定降级规则并接告警

把 4.7 的 `parse_status` 落成字段，给 `failed`/`encrypted` 接上告警（哪怕只是打日志 + 落隔离目录）。**实验的最低交付是「每份文档都有状态，且没有空块入库」。**

## 档位 B · 本地练习（无企业语料）

用一份公开技术规范 PDF + 一份自制「扫描件」做对照：

```bash
# 1) 取一份有层级、有表格的公开 PDF（如某开源规范/白皮书）
# 2) 把其中几页“降级”成扫描件：先渲成图，再逐页 OCR
pdftoppm -r 200 -png -f 1 -l 3 report.pdf /tmp/page
for f in /tmp/page-*.png; do tesseract "$f" "${f%.png}" -l chi_sim+eng --psm 6; done

# 3) 与原文本层做三方对照：文本层 / pdftotext -layout / OCR
pdftotext -layout -f 1 -l 3 report.pdf -
```

**关键观察点**：对比「原文本层」与「OCR 结果」的字符级差异——OCR 会**丢小数字、混淆形近字、打乱表格列**。这正是为什么 OCR 必须配抽样验收与置信度门槛（`tesseract ... tsv` 的 `conf` 列可统计）。

## 档位 C · 纸上评审（30 分钟）

下面是一段「解析完成」的处理代码。找出它静默丢内容 / 破坏结构的 **5 个问题**：

```python
def parse_pdf(path):
    doc = fitz.open(path)
    text = ""
    for page in doc:
        t = page.get_text()
        if not t.strip():
            continue                                 # ①
        text += t + "\n"
    text = re.sub(r"-\n", "", text)                  # ②
    for hf in header_footer_list:
        text = text.replace(hf, "")                  # ③
    return [{"text": text[i:i+800]} for i in range(0, len(text), 800)]   # ④⑤
```

<details><summary>对照答案（先写完再看）</summary>

1. **`continue` 静默丢页**：空白页可能正是图片页/扫描页，应记为待 OCR 或 `low_text`，而不是跳过。
2. **`re.sub(r"-\n","")` 无差别合并连字符**：会把「A-1」「pH-」这类非断词也粘起来，也会破坏行尾本就合法的连字符。
3. **页眉页脚用「出现即删」**：`header_footer_list` 若含常见词，会把正文同名短语一并删掉；应按「多页重复」判定，并记录命中处数。
4. **在字符层 `[i:i+800]` 硬切**：无视标题/段落/表格边界，**表格与代码会被切断**——这本是切分阶段该做、且必须结构感知的事。
5. **没有 `parse_status`、没有 `section_path`、没有表格识别**：产出的中间表示无法支撑引用锚点、无法判废、无法给下游告警。

</details>

### 最后：把「不可用」显式化

无论哪一档，收尾时给出这句话——填不出来说明解析阶段还没闭合：

> 「本语料共 **__** 类文档，走 **__** 条解析链路；解析失败会产出 `parse_status ∈ {__}`，其中 **__** 类必须人工兜底，抽样验收通过标准是 **__**。」
