# 🧪 动手实验 · 里程碑 11

> **本里程碑的交付物**：① 引用锚点粒度决策记录 ② 生成后校验脚本（越界/不支持/无引用三类）③ 幻觉引用统计与发布门禁值 ④ 权限一致性三道防线落地 ⑤ 点击跳转的前端契约 ⑥ 引用覆盖率回归基线。
> **验收标准**：拿 20 条真实回答跑校验脚本，能列出每条的「越界引用数 / 不支持引用数 / 无引用断言数」；点任意一个引用都能跳到原文；用越权问题提问，返回里既无内容也无引用。
>
> 三档任选：**档位 A 真实项目**（接你自己的生成结果与文档存储）／**档位 B 本地练习**（起 vLLM 或任意 OpenAI 兼容端点，让模型在给定证据上生成，再用脚本校验）／**档位 C 纸上评审**（30 分钟，判断力训练）。

## 档位 A · 真实项目（推荐）

### 1. 先定锚点，再写代码

回到生成时保存的证据映射表，**把每个块补上机器锚点（`chunk_id` + 块内字符区间）与人读锚点（标题路径 + 页码）**。没有这两组坐标，后面校验与跳转都做不了。写一句决策记录：为什么选双锚点、字符区间为什么相对块而非整篇。

### 2. 落地校验骨架（在线第一档 + 离线第二档）

把 guide 11.4 的 `verify_answer` 实现在生成与展示之间，**做成必经闸门**：

```text
在线：词面重叠 + 数字/实体对齐 —— 拦「越界引用」与「数字幻觉」，两秒内出结果
离线：NLI 蕴含小模型 / LLM 判官 —— 抽检与回归，发现「引用与结论不符」的软性问题
```

先打印每条回答的三类问题数，别急着拦截，看清分布再定策略。

### 3. 权限一致性红队

用三种越权提问打自己的系统：① 问无权限文档的内容；② 引诱它引用一个无权限块（构造检索期过滤缺陷）；③ 生成时有权限、展示前撤销权限。**三种都不该泄露内容或引用。**

### 4. 把覆盖率做成门禁

定义写死（见 guide 11.8），跑黄金集记录基线。**覆盖率、不支持率、幻觉引用条数**三者一起进 CI 门禁。

## 档位 B · 本地练习（给定证据，校验生成）

无 GPU 也能做本实验的核心：**校验层不依赖大模型**。

```bash
# 1) 起 OpenAI 兼容端点（有 GPU 用 vLLM；无 GPU 用 ollama CPU 小模型兜底）
python -m vllm.entrypoints.openai.api_server \
  --model Qwen/Qwen2.5-7B-Instruct --served-model-name qwen7b --port 8000

# 2) 给定 3 个证据块（编号 1/2/3），用 m10 模板 + m11 引用契约段让模型回答

# 3) 抽出回答里出现的所有引用编号
grep -oE '\[\[[0-9]+\]\]' answer.txt | sort -u
```

```bash
# 4) 越界引用检测：编号落在证据集 {1,2,3} 之外即为越界
python3 check_cites.py answer.txt   # 见下
```

`check_cites.py` 骨架（可直接改成你的校验闸门）：

```python
import re, sys
ans = open(sys.argv[1]).read()
cites = sorted(set(map(int, re.findall(r'\[\[(\d+)\]\]', ans))))
EV = {1, 2, 3}                       # 本次证据集编号
print('出现的引用:', cites)
print('越界引用:', sorted(set(cites) - EV) or '无')
print('有效引用数:', len(re.findall(r'\[\[(\d+)\]\]', ans)), '句数:', ans.count('。'))
```

**关键观察**：故意把问题改成证据不支持的样子，看模型是否「随手挂一个真实编号」——那正是最难查的第二类幻觉引用，只有蕴含判定才能抓。

## 档位 C · 纸上评审（30 分钟）

给定证据 `[1] 员工手册 3.2：正式员工年假 15 天`、`[2] 考勤制度：病假需提前 1 天报备`。判断三条回答的引用问题：

```text
问题：年会能报销多少？

回答甲：年会费用按实际支出全额报销。[[3]]

回答乙：病假需提前一天报备。[[2]]

回答丙：根据员工手册，年假为 15 天。[[1]]
```

<details><summary>对照答案（先写完再看）</summary>

1. **回答甲 = 越界引用 + 无依据**：证据集只有 `[1][2]`，`[[3]]` 是不存在的块（第一类幻觉引用）；且「全额报销」在两条证据里都没有。
2. **回答乙 = 引用真实但不相关（答非所问）**：`[[2]]` 确实存在、内容也支持该句，但**它回答的不是所问的问题**。这说明校验要分两层：引用是否支持该句（通过），以及该句是否回应了问题（不通过）。企业场景里，这属于「跑题」而非「幻觉引用」。
3. **回答丙 = 合格**：引用真实、内容支持结论、且回应了问题。
4. **延伸**：甲若出现在生产，必须被在线校验直接拦截；乙需要「相关性/意图」判据补位。**有引用 ≠ 有依据 ≠ 答对了问题**，三道关依次是：编号有效、引用支持句子、回答切题。

</details>

### 最后：把三项指标写成回归基线

无论哪一档，收尾时记一行基线：`引用覆盖率 / 不支持引用率 / 每千次幻觉引用条数`，下一里程碑的评测体系要拿它当门禁。
