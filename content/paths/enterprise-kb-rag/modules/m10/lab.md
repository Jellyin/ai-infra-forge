# 🧪 动手实验 · 里程碑 10

> **本里程碑的交付物**：① 可复用生成提示词模板 ② 上下文预算与截断策略 ③ 拒答判据与误拒率 ④ 会话记忆清单 ⑤ 生成模型选型与成本估算。
> **验收标准**：拿 20 道黄金集问题跑一遍，能亮出「引用正确率、漏拒率、误拒率、P95 延迟」四个数；随便抽一次拒答，你能指出它命中了哪条判据。
>
> 三档任选：**档位 A 真实项目**（接你自己的检索结果与语料）／**档位 B 本地练习**（起 vLLM 或任何 OpenAI 兼容端点，用小模型做对照实验）／**档位 C 纸上评审**（30 分钟，判断力训练）。

## 档位 A · 真实项目（推荐）

### 1. 固化提示词模板并落成代码常量

把 guide 10.2 的模板存成 `prompt_template.txt`，用占位符渲染，**模板不进业务逻辑、单独可版本化**。第一件事是让编排层把 `[[n]]` 的编号与最终证据集对齐——先打印出「证据编号 → chunk_id → 标题」映射表，后面所有校验都基于它。

### 2. 组装一次，量三个数

对黄金集里的问题逐条生成，统计：

```text
引用正确率 = 结论被证据真实支持的样本数 / 总样本数
漏拒率     = 应拒却给出答案的样本数 / 应拒样本数
误拒率     = 可答却被拒的样本数 / 可答样本数
```

**先画「相似度阈值 vs 漏拒/误拒」的曲线**，再选 τ。别直接抄 guide 里的示例阈值。

### 3. 截断与预算实验

固定模型与证据集，改「证据块数（3/5/8）」跑三次，记录质量与 P95 延迟。你会看到边际收益递减的拐点——**那就是你的证据预算**。

## 档位 C · 纸上评审（30 分钟）

下面三份是某个系统对同一问题的三种回答（证据集固定为 `[1][2][3]`）。判断：**哪份的引用是幻觉？哪份该拒答？哪份合格？**

```text
问题：试用期员工的年假计算方式是什么？

回答甲：
试用期员工按入职月份折算年假，满 3 个月可享 5 天。[[2]][[7]]

回答乙：
INSUFFICIENT_EVIDENCE: 现有证据只说明了正式员工的年假规则，
未说明试用期是否折算、按什么比例折算。

回答丙：
试用期员工年假通常按照劳动法第 45 条执行，一般为 5 至 15 天，
具体以公司制度为准。[[1]]
```

<details><summary>对照答案（先写完再看）</summary>

1. **回答甲是幻觉引用**：`[[7]]` 越界——证据只到 `[3]`，`[7]` 是不存在的块，必是模型编的编号。且「5 天」这个具体数值要核对 `[2]` 是否真的写了。
2. **回答乙合格且正确**：证据不足时明确拒答、并说明缺什么，是 10.4 判据命中的标准动作。
3. **回答丙该拒答却硬答**：`[[1]]` 看似有引用，但引用的证据若与「劳动法第 45 条」无关，就是「引用与结论不符」的幻觉引用；「通常/一般/以制度为准」是典型的搪塞话术。**有引用标记 ≠ 有依据。**
4. 补充判据：三份都该进「生成后校验」——甲查编号越界、丙查引用与结论的支持关系。

</details>

### 最后：把四个数写进回归基线

无论哪一档，收尾时把「引用正确率 / 漏拒率 / 误拒率 / P95 延迟」记成一行基线数字，下一里程碑的引用校验层要拿它做回归对比。
