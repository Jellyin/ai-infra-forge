# 里程碑 1 · 立项：把「知识库」翻译成可验收的目标

> **本里程碑的交付物**：一页纸的目标与范围说明、语料盘点表、延迟/成本预算表、「本期不做」清单。
> **验收标准**：任意第三方读完这四个文件，能说出「这个知识库给谁用、答错代价多大、多少毫秒内必须答、本期不做什么」。

## 1.1 三类提问者，三类问题

「做一个企业知识库」这句话没有工程含义。先把它拆开：

| 提问者 | 典型问题 | 对系统的要求 |
|---|---|---|
| 一线员工（自助） | 「年假怎么请」「这个报错怎么解」 | 覆盖度第一，允许答「没找到」 |
| 熟练同事（查证） | 「M4 评审里定的超时是多少」 | **必须给引用**，他要的是证据不是答案 |
| 决策者（汇总） | 「三个季度内哪些条款变更过」 | 多跳检索 + 汇总，容错最低 |

三类问题对应的**检索形态完全不同**：第一类是单跳事实，第二类要精确匹配（编号、术语、版本），第三类是多跳推理。**用一套策略通吃，通常意味着三件事都做不好。**

## 1.2 答错的代价分级：它决定架构，而不是反过来

这是立项阶段最重要的一张判断表——它直接决定你要不要花时间做引用、拒答和人工兜底：

| 答错代价 | 例子 | 架构上的必然选择 |
|---|---|---|
| **低**（自己再查一遍） | 内部工具的用法 | 可以只做检索不做生成；无引用也能接受 |
| **中**（返工/沟通成本） | 流程、配置、环境说明 | **必须双向链接引用**；答案要给人确认的机会 |
| **高**（合规/资损/安全） | 合同条款、计费规则、权限说明 | 引用 + 拒答 + 强制人工复核；且必须有越权防护与审计 |

**一旦某类问题被判为「高代价」，后面所有里程碑的成本都会跟着上升**（评测要更严、审计要更全、回滚要更快）。所以这张表必须在写第一行代码之前定下来。

## 1.3 先定 SLO，再选模型

延迟与成本预算不是上线前才估的，它**反向决定**技术选型：

```
首字延迟(TTFT) 预算 ──► 能否用大模型 / 要不要缓存 / 要不要流式
端到端  预算 ──► 检索跳数上限、reranker 能不能上、多跳要不要拆
单次成本预算 ──► 上下文长度上限、模型分级策略、缓存收益的目标
```

一张可用的预算表长这样（数字按你的场景填，重点是**每一项都要有来源**）：

| 项 | 目标 | 依据 |
|---|---|---|
| 首字延迟 | ≤ 2s | 一线自助场景，超过就没人用 |
| 端到端 | ≤ 8s | 允许一次多跳 |
| 单次问答成本 | ≤ ¥0.05 | 按日活 × 人均次数反推的月度预算 |
| 可用性 | 99.5% / 月 | 内部系统等级（不允许它拖垮工单流转） |

**「先定 SLO 会反向决定选型」**：预算紧 → 先做小模型 + 缓存 + 短上下文；预算宽 → 才谈得上多跳与重排。

## 1.4 语料盘点：把「有什么」变成一张能管理的表

没有语料盘点，后面的切分、解析、权限、评测全部无从下手。盘点表至少要有：

| 文档源 | 类型 | 规模 | 更新频率 | 权限归属 | 负责人 |
|---|---|---|---|---|---|
| 共享盘 | PDF/Office | ~8k 文件 | 不定期 | 按目录 | 各业务线 |
| Confluence | 页面 | ~2k 页 | 每周 | 空间权限 | 平台组 |
| 工单系统 | 富文本 | ~50k 条 | 实时 | 按项目 | 服务台 |

盘点时就该顺带**发现三类坑**：① 有大量扫描件（解析成本翻倍）；② 权限归属混乱（无法映射成过滤条件）；③ 有源站即将下线（接入方式要改）。

## 1.5 成功标准：可验收 vs 不可验收

| 不可验收（无法判定） | 可验收（能测） |
|---|---|
| 「回答要准确」 | 「黄金集 200 题中，事实类正确率 ≥ 85%，引用覆盖率 ≥ 90%」 |
| 「要好用」 | 「一线自助场景 TTFT ≤ 2s，P95 端到端 ≤ 8s」 |
| 「要安全」 | 「越权红队用例 100% 被拦；不可答问题拒答率 ≥ 95%」 |

判据很简单：**能不能写出测量方法**。写不出来的指标，在验收会上只会变成争论。

## 1.6 「本期不做」清单：比 To-do 更重要

项目失控的典型方式是范围蔓延。立项时明确写下不做的事，例如：

- 不做多模态（图片/音视频）——只接文本与表格
- 不做写回（不自动修改源文档）
- 不做全量历史工单（只接近 12 个月）
- 不做跨语言检索

**每一条都要写明「什么时候重新评估」**，否则它会在第三次评审会上被悄悄推翻。

## 1.7 本里程碑的判断力

- 有人问「用什么模型/什么向量库」时，先反问：**给谁用、答错代价多大、多少毫秒内要答完**。
- 看到「准确率要 95%」这类指标，追问：**谁来测、怎么测、测什么集合**。
- 立项文档里没有「本期不做」，就还没有立项。
