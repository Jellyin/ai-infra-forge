# 🧪 毕业项目 II（Day 27）· 实现任务书

## 最小实现范围（对照 guide）

只做一条链：提交→队列→训练（含 ckpt）→评测红线→合并→vLLM→网关→验收。

## 验收对照

- [ ] 一条命令跑通（submit.sh / main.py）
- [ ] **评测红线是自动拦截**（eval loss 超标 exit 1）——不是人工看
- [ ] **checkpoint 真存真恢复**（kill 后能续）——不许 mock
- [ ] README（架构图+运行法+关键数字）
- [ ] DECISIONS.md ≥5 条决策记录（为什么+放弃了什么）
- [ ] 踩坑记录 ≥3 条（症状→定位→修复→知识点溯源）

## 纸上档验收

影子实现文档：每环的输入/输出/接口契约齐全，别人能照着开工。
