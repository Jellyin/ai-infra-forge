# 🧪 毕业项目 I（Day 26）· 方案设计任务书

> 按 guide 的五部分结构完成 2-3 页方案文档。本任务书给「验收对照表」——写完自查。

## 验收对照（每项 pass/fail）

- [ ] 需求翻译表 ≥4 行（业务说法→技术约束，含 SLO 数字化）
- [ ] 架构图四层齐全（入口/推理/训练/支撑），每层一句职责
- [ ] 三本账有计算过程（不是结论——要能复算）
- [ ] ≥3 个选型带「为什么不是 B」
- [ ] SLO/北极星/三个风险预案齐全

## 常见失败模式（写了但不合格的形态）

- 容量账只写「需要 8 张卡」不写推导 → 重写（数字从哪来是评分主体）
- 选型只写「选 vLLM」不写放弃项 → 补「考虑 TRT-LLM 但…」
- 风险预案写「加强监控」这类空话 → 必须落到 Day 23 的具体场景（XID79 怎么办）
