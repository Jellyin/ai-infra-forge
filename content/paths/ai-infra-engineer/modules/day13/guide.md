# Day 13 · Megatron/DeepSpeed 实操

> 目标：跑通一次多卡微调，理解并行参数的选择逻辑

## 两大框架的定位差异（面试常考）

| | Megatron-LM | DeepSpeed |
|---|---|---|
| 出身 | NVIDIA 官方 | 微软 |
| 强项 | **3D 并行**（TP+PP+DP）原生融合、性能极致 | **ZeRO 显存分片**、易用性（wrap 一行） |
| 适合 | 从头预训练大模型、追求 MFU 极致 | 微调/中等规模训练、快速落地 |
| 代价 | 配置复杂、侵入代码 | 通用性好但极致性能略逊 Megatron |

**选型一句话**：预训练追求性能上限选 Megatron 体系；微调/工程优先选 DeepSpeed（或 HuggingFace Trainer + accelerate 生态）。

## ZeRO 三级——DeepSpeed 的核心

Zero Redundant Optimizer 的思想：**DDP 里每卡都冗余存了全量优化器状态/梯度/参数——把冗余切掉**：

| 级 | 分片什么 | 显存节省（7B Adam） | 额外通信 |
|---|---|---|---|
| ZeRO-1 | 优化器状态 | 4× | 少 |
| ZeRO-2 | +梯度 | 8× | 中 |
| ZeRO-3 | +参数 | 16×~N× | 大（接近 TP 的量） |

**运维视角**：ZeRO-3 与 FSDP 本质同族（参数分片+用时聚合）。 ZeRO-1/2 不改参数存储，几乎免费拿 4-8 倍显存——**默认开 2 档，不够再上 3**。

## 三维并行怎么组合（必会的推理题）

8 卡训练 70B 模型（全参），给一套并行方案：

```
训练态显存 ≈ 16B/参数 × 70B = 1120GB（权重+梯度+Adam）——8×80G=640GB 装不下
→ 必须加 ZeRO/FSDP 分片：TP=2（机内 NVLink，权重装不下）+ ZeRO-1（优化器分片）
→ DP=4 份数据并行
→ 8 卡 = TP2 × ZeRO-1 × DP4（纯 DDP/TP 组合装不下，这是 70B 的现实）
```

**组合规则**（面试给卡数要能现场推）：
1. **TP 留机内**：TP 通信量最大（每层前反向都要 AllReduce），必须 NVLink（跨机 TP 性能塌方）
2. **PP 跨机用**：PP 通信量小（只在切分点传激活），代价是气泡利用率损失
3. **DP/ZeRO 填余量**：最便宜；卡不够先上 ZeRO 分片再谈 TP/PP
4. 优先级：能 DP/ZeRO 解决就不上 TP（通信最重），TP 装不下再叠 PP（有气泡代价）

**气泡**（bubble）：PP 把层切 N 段，前一段没算完后一段空等——`气泡率 ≈ (N-1)/(总micro-batch数+N-1)`。micro-batch 越多气泡占比越小。
